# CoolShop & Combat System

Мой личный проект скриптов для Minecraft-сервера на базе **Skript**. 
Включает в себя полностью рабочую экономику, GUI-магазин и боевую систему.

## 🛠️ Установка

1. Скачайте все файлы `.sk` из этого репозитория (или скачайте `.zip` архив через кнопку `Code -> Download ZIP`).
2. Перекиньте файлы в папку вашего сервера: `plugins/Skript/scripts/`
3. В консоли сервера введите: `sk reload all`

## 📋 Что внутри?

*   **`shop.sk`** — Магазин (`/shop`), встроенная экономика (`/bal`, `/givecoin`) и редактор магазина (`/shopadmin editor`).
*   **`coin_get.sk`** — Награды за убийства. За игроков дают от 150 до 500 монет, за мобов — от 5 до 20.
*   **`combat.sk`** — Красивый боевой HUD (Kills / Combat) в Action Bar над хотбаром.

## ⚠️ Требования

*   **Ядро:** Paper 1.21.11 (или новее)
*   **Плагин:** Skript (версия 2.7+ или 2.17.0)
*   **Java:** 21+
