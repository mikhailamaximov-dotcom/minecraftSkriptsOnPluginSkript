🇬🇧 English
📋 Requirements
Before installing, make sure your server has the following:

Server Software: Paper or Purpur (recommended: Paper 1.21.11).

Skript: Version 2.7.0 or newer (Recommended: Skript 2.17.0).

Java: Version 21 or higher.

Vault (Optional): Required only if you want to use external economy plugins instead of the built-in one.

🛠️ Step-by-Step Installation
Download the .zip file from the "Versions" tab.

Extract the archive using WinRAR or 7-Zip.

Open your server's main folder and navigate to:
plugins/Skript/scripts/
(If the scripts folder is missing, create it manually).

Move (Drag & Drop) all the .sk files from the archive into this scripts folder.

Go to your server console and type:
sk reload all
(Or just restart your server).

Check the console for any red errors. If there are none, the installation was successful!

💡 Recommended Versions (Tested)
Minecraft: 1.21.11

Skript: 2.17.0

Paper: 1.21.11 (Build 132+)

🇷🇺 Русский
📋 Требования
Перед установкой убедитесь, что на вашем сервере есть следующее:

Ядро сервера: Paper или Purpur (рекомендуется: Paper 1.21.11).

Skript: Версия 2.7.0 или новее (Рекомендуется: Skript 2.17.0).

Java: Версия 21 или выше.

Vault (Опционально): Нужен только в том случае, если вы хотите использовать сторонние плагины экономики вместо встроенной.

🛠️ Пошаговая установка
Скачайте архив .zip во вкладке "Versions" (Версии).

Распакуйте архив с помощью WinRAR или 7-Zip.

Откройте главную папку вашего сервера и перейдите по пути:
plugins/Skript/scripts/
(Если папки scripts нет — создайте её вручную).

Перекиньте (или перетащите мышкой) все файлы .sk из архива в эту папку scripts.

Зайдите в консоль сервера и введите команду:
sk reload all
(Или просто перезапустите сервер).

Проверьте консоль на наличие красных ошибок. Если их нет — установка прошла успешно!
